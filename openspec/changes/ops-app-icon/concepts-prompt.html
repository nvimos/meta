Ops prompt icons

All four keep concept A's dark tile, folded chevron and green block. Each adds one thing so the icon says "a front end for operations", not "a terminal": a window frame, a list of tasks, the letter o, or a cursor that is itself a window.

A. Prompt the starting point

Chevron and block cursor. Clear at 16 px, but it reads as a shell.

A1. Window prompt inside an app frame

The tile gets a title bar with three dots, so the prompt sits inside a desktop window: a GUI wrapped around the editor. It changes A the least and still reads at 16 px, where the bar becomes a lighter top edge.

A2. Board cursor heads a task list

The green cursor becomes the first row of a list, with two blue rows below it. It points at what Ops shows: tasks, files, pull requests. At 16 px the rows merge into stripes, which still reads as a list.

A3. o› the o of ops, then the prompt

A green ring before the chevron spells "o›", a short monogram for Ops. It ties the icon to the name, but drops the cursor, so the link to Neovim is weaker.

A4. Opens the cursor is a window

The block cursor grows a title bar and a pane: the prompt produces a window. It keeps the chevron-plus-green-block shape of A exactly, and at 16 px falls back to A.
