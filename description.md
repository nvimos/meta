# intended use case of the project

The intended outcome is building an environment that is really really specialized for software development and operations workflows. Code navigating, reviewing agents' work, planning projects, testing implementations, navigating documentation, spinning up infrastructure and receiving reports from monitoring. Conceptually, it's a shell to the operating system and resources that run in external environments. And also an interface to project management tools. It's a dashboard for developers, who do more than just coding. It's based on Neovim but I also need a native gui for the desktop for windows and linux and mac and android. A part of the vision or focus is on local workflows without external service dependencies beyond infrastructure. Another way to describe it is a modernized environment that takes a couple of months to build that I can use for working effectively in the modern agentic paradigm and keep learning new technologies. Hopefully this work is also useful to other people.
